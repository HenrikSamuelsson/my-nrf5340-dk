# nRF Connect for VS Code

*nRF Connect for Visual Studio Code* is a set of Visual Studio Code extensions that supports building, flashing, and debugging embedded applications based on the *nRF Connect SDK*.

Once configured, it provides an integrated graphical user interface within
VS Code that abstracts much of the underlying toolchain complexity, such as `west` commands, CMake configuration, and SDK/toolchain selection, while still allowing direct access to the underlying build system when needed.

The extension is designed to support development within Nordic Semiconductor’s software ecosystem, particularly for SoCs such as the nRF52 and nRF53 series.
